## What to build

관리자가 개별 장비를 등록·수정하면 직원이 장비 목록과 상세에서 자산번호와 사용 가능 상태를 확인한다. 데이터는 재시작 후에도 유지된다.

## Current status

로컬 구현·검증 완료. 관리자 장비 등록·수정, 직원 목록·상세 조회, 검색과 SQLite 저장을 연결했다. 실제 화면에서 DEMO-001 테스트 장비를 등록하고 보관 위치를 수정했으며 직원 계정의 조회 전용 화면도 확인했다. API·SQLite 통합 테스트, 프론트 사용자 행동 테스트와 검색 공백 실패→수정→통과를 검증했다. PR·GitHub CI·main 반영은 아직 남아 있으므로 이슈는 열린 상태로 유지한다.

## Acceptance criteria

- [ ] 자산번호·장비명·모델·분류·설명·보관 위치·상태를 저장하고 사진은 제외한다.
- [ ] 관리자 등록·수정 화면과 직원 목록·상세 화면을 API와 SQLite에 연결한다.
- [ ] 자산번호 고유성을 DB에서 보장하고 중복·잘못된 입력을 안내한다.
- [ ] 직원은 조회만 가능하며 자산 수정 API는 거절한다.
- [ ] 빈 목록·조회 실패·저장 실패·로딩 상태를 이해하기 쉽게 표시한다.
- [ ] 빈 DB의 초기 마이그레이션과 실제 파일 DB 재연결 후 자산 보존을 검증한다.
- [ ] 실제 API·SQLite 통합 테스트와 주요 폼 동작 테스트를 추가하고 PR 빌드·테스트를 통과한다.
