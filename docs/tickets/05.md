## What to build

관리자가 대기 신청을 승인하면 즉시 대여 중으로 바뀌며 같은 자산의 다른 대기 신청은 자동 거절된다. 수동 거절 시 직원은 사유를 확인한다.

## Acceptance criteria

- [ ] 관리자 전체 대기 신청 목록과 승인·사유 입력 거절, 직원 처리 결과·본인 대여 조회를 연결한다.
- [ ] 승인 즉시 대여를 시작하고 별도 장비 배정·인도 확정 단계는 만들지 않는다.
- [ ] 승인과 같은 자산의 다른 대기 신청 자동 거절을 한 트랜잭션으로 처리하고 자동 거절 사유를 남긴다.
- [ ] 한 자산에는 진행 중 대여가 최대 한 건만 존재하도록 DB에서 보장한다.
- [ ] 취소·이미 처리된 신청과 사용 불가능한 자산은 승인하지 않으며 충돌을 안내한다.
- [ ] 기한이 지난 대기 신청의 승인 처리 정책은 구현 전에 기록하고 미확정 사항을 사용자 확정으로 취급하지 않는다.
- [ ] 실제 API·SQLite로 두 신청 동시 승인·더블 클릭·취소 후 승인·트랜잭션 실패 시 부분 변경 방지를 검증한다.
- [ ] 승인 후 관련 목록을 갱신하고 브라우저 핵심 신청→승인 흐름과 PR 빌드·테스트를 확인한다.
