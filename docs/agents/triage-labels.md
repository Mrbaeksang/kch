# 이슈 분류 라벨

| 역할 | 실제 라벨 | 의미 |
| --- | --- | --- |
| needs-triage | needs-triage | 내용 검토 필요 |
| needs-info | needs-info | 요청자의 추가 정보 대기 |
| ready-for-agent | ready-for-agent | 에이전트가 작업할 수 있는 명세 |
| ready-for-human | ready-for-human | 사람의 구현 작업 필요 |
| wontfix | wontfix | 진행하지 않음 |

명세를 확정해 게시할 때 ready-for-agent를 사용한다. 운영 자격 증명 미제공을 구현 완료나 배포 완료로 표시하지 않는다.
