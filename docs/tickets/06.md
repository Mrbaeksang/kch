## What to build

직원이 사용 중 장비의 반납을 요청하면 확인 대기로 유지하고, 관리자가 실제 반환을 확인해야 대여를 종료한다. 거절하면 직원이 사유를 확인하고 다시 요청할 수 있다.

## Acceptance criteria

- [ ] 직원 반납 요청과 관리자 확인 대기 목록·완료·사유 입력 거절 화면을 실제 API·SQLite와 연결한다.
- [ ] 반납 요청 중에도 진행 중 대여를 유지하며 새 대여를 허용하지 않는다.
- [ ] 반납 완료 시 대여 종료와 자산의 다시 신청 가능한 상태를 원자적으로 반영한다.
- [ ] 거절 시 대여를 사용 중으로 유지하고 사유를 남기며 재요청을 허용한다.
- [ ] 직원은 본인 대여만 요청하고 관리자는 완료·거절을 처리한다.
- [ ] 연체 여부를 이유로 반납 요청을 차단하지 않는다.
- [ ] 실제 API·SQLite로 중복 완료·다른 직원 요청·거절 후 재요청·부분 변경 방지를 검증한다.
- [ ] 브라우저에서 신청→승인→반납 요청→관리자 확인 흐름과 PR 빌드·테스트를 확인한다.
