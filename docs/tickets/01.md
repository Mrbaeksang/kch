## What to build

프론트·Go 백엔드·SQLite를 Docker Compose로 로컬 실행하고 직원·관리자 개발 테스트 계정으로 로그인·로그아웃한다. 이 기반으로 후속 업무 기능을 개발한다.

사용자 결정(2026-10-21): 실제 Google 로그인 구현·운영 연결·최종 검증은 #10의 최종 검증 단계로 이관한다. 운영 서비스의 Google 로그인 전용 정책과 등록 이메일 제한은 유지한다.

## Acceptance criteria

- [x] React·Vite 프론트와 Go·chi API, SQLite를 연결하여 로컬에서 실행한다.
- [x] SQLite 초기 마이그레이션을 자동 적용하고 컨테이너 재생성 후 DB 파일을 보존한다.
- [x] 직원·관리자 개발 테스트 로그인 버튼과 로그아웃을 제공한다.
- [x] 무작위 세션 식별자를 HttpOnly·SameSite 쿠키로 전달하고 계정의 실제 역할·활성 상태를 DB에서 조회한다.
- [x] 로그아웃한 세션과 비활성 계정의 기존 세션 접근을 차단한다.
- [x] 개발 환경과 명시적 활성화 설정을 함께 요구하고 운영 환경 활성화 요청을 차단한다. 로컬 Origin 제한을 적용한다.
- [x] 프론트 빌드·테스트, Go 통합 테스트·race 검사·정적 검사를 로컬에서 통과한다.
- [x] 개발 테스트 계정의 두 역할 로그인·로그아웃을 로컬 브라우저에서 확인한다.
- [ ] 변경을 PR로 제출하고 GitHub CI에서 프론트·백엔드 검사를 통과한 뒤 main에 병합한다.
