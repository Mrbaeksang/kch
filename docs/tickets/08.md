## What to build

관리자가 자산의 수리 상태를 변경하거나 삭제 처리한다. 수리 중에는 신청을 차단하며 자산 삭제 후에도 과거 기록은 유지한다.

## Acceptance criteria

- [ ] 수리 전환·수리 완료·보관 방식 삭제 화면과 API를 SQLite에 연결한다.
- [ ] 수리 중 전환과 기존 대기 신청 자동 거절을 같은 트랜잭션으로 처리하고 원인을 표시한다.
- [ ] 수리 중에는 새 신청을 차단하고 수리 완료 후 사용 가능한 자산의 신청을 재개한다.
- [ ] 대여 중 또는 반납 확인 대기인 자산은 삭제할 수 없다.
- [ ] 삭제는 보관 처리이며 신규 신청을 차단하고 자산번호·대여·반납 이력을 보존한다.
- [ ] 이미 대여 중인 자산의 수리 전환과 보관 시 대기 신청 처리 정책은 구현 전에 기록한다.
- [ ] 실제 API·SQLite로 승인과 수리 전환 경합·대여 중 삭제 차단·보관 후 이력 보존·직원 권한 거부를 검증한다.
- [ ] 목록과 상세에 결과를 반영하고 PR 빌드·테스트를 통과한다.
