## What to build

직원이 개별 자산의 반납 예정일을 입력하여 신청하고, 본인 신청 목록에서 상태를 확인하거나 승인 전 신청을 취소한다.

## Acceptance criteria

- [ ] 개별 자산 선택·반납 예정일 필수 입력·신청 결과 확인 화면을 API·SQLite와 연결한다.
- [ ] 같은 자산에 여러 직원의 대기 신청을 허용한다.
- [ ] 대여 중·수리 중·보관된 자산에 대한 새 신청은 서버에서 차단한다.
- [ ] 직원은 본인 대기 신청만 취소하고 다른 직원 신청의 조회·취소는 할 수 없다.
- [ ] 반납 예정일은 KST 날짜로 처리하고 브라우저 시간대에 따라 날짜가 바뀌지 않는다.
- [ ] 같은 직원의 동일 자산 중복 신청 방지와 유효한 신청 날짜 범위는 구현 전에 정책을 기록한다. 부모 명세에서 이미 확정된 것으로 간주하지 않는다.
- [ ] 실제 API·SQLite로 신청·취소·권한·상태 충돌을 검증하고 폼의 입력 오류 및 PR 빌드·테스트를 확인한다.
